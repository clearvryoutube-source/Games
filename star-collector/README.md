# ⭐ Star Collector

A clean, family-friendly original arcade game, added by Muse for ClearVRGT.

**How to play:** Open `index.html` in any browser — no install, no sign-in.
Collect 20 stars in 60 seconds. Dodge the red blocks.
Move with WASD or arrow keys, or touch / click to move.

**Rules followed:** no porn, no sex, nothing inappropriate. Just stars, blocks, and fun.

Made with plain HTML + JavaScript, no libraries, no assets to download.
